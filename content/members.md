# Members (the member gallery page)

One member on each line that starts with a dash, with bars ( | ) between the parts:

    - photo file | name | the line under the name

The photo file is a picture in the photos folder (the older ones are in the
archive folder, and are found there by the same name). The line under the name
is free words: boater or rider, the boat, the message board handle.
To add a member, add a line. To take one off, delete the line. The order here
is the order on the page.

These lines were taken from the old site on 20 November 2026 as they were
written there. The officer titles were brought up to date the same day; the
boats may be out of date.
