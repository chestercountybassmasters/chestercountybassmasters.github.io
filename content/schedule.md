# Schedule

Each season starts with a line like "## Club 2026". Under it, one tournament on
each line, with bars ( | ) between the parts:

    date | water | ramp | note

- The date is written as it should show, for example "Apr 11".
- The note is optional. Write "Canceled" there if the tournament was canceled.
- Words in (round brackets) after the water show in small print under it.
- For the two-day Classic, give each day its own line and start the water with
  "Classic, day 1:" and "Classic, day 2:".

If a season's dates are not set yet, write one line of plain words instead and
it shows as it is. The Opens season is written that way: one line of plain
words, and a line starting "short:" with the short form for the home page.

A line starting "notice:" under a season shows in a tinted box with that
season's dates, with its first sentence in bold. Take the line out when the
notice no longer applies.

The link to each result is added by itself when the result is in the data.
